# 光影壁纸 Windows 客户端首版 PRD

版本：v1.0 · 2026-10-30  
状态：产品范围已确认；M0 尚未验收，首版尚未交付  
适用范围：Windows 客户端、现有 Java 后端、必要的管理端操作

本文是**首版产品需求的唯一主文档**。已接受的 [公开壁纸与账号边界 ADR](adr/0001-public-wallpapers-and-account-boundaries.md) 和 [CUSTOMER 账号开通 ADR](adr/0002-customer-accounts-with-admin-provisioning.md) 是决策约束；[首版执行规格](../.scratch/client-wallpaper-v1/spec.md) 记录实施与测试细节；[早期 API 调查](壁纸API接入PRD.md) 和 [账号成长方案](客户端账号收藏与成长体系方案.md) 保留背景和候选设计。旧文档与本文冲突时，以本文及已接受 ADR 为准。实现进度以 [M0 验证报告](M0账号认证验证报告.md) 和 [M0 安全续期进展](M0安全续期实现进展.md) 为准，不把需求当成已实现能力。

## 1. 目标与成功标准

使用者在 Windows 应用中直接浏览、预览、下载并设置后台管理的公开壁纸；需要跨设备保存个人收藏时再登录。首版按正式运营交付，由管理员开通账号，暂不提供自行注册；复用现有后端和本地播放能力，保持基础壁纸使用免费。

首版发布时，游客无需账号即可完成“浏览 → 下载 → 设置桌面”；用户账号可完成“登录 → 收藏/取消 → 换设备刷新收藏”。实际使用时登录有效期滚动延长，连续六个月没有实际使用才过期；后台自动刷新不算活跃。退出、改密、冻结、重置或凭据撤销能提前终止相应登录。公开浏览、当前桌面播放和已下载壁纸不因账号失效中断。

## 2. 用户与范围

| 角色 | 能力与边界 |
| --- | --- |
| 游客 | 浏览、搜索、筛选、预览、下载和设置公开壁纸；不能访问个人云端收藏。 |
| CUSTOMER 用户账号 | 游客的全部能力；登录后管理自己的一个默认收藏列表，可在不同设备刷新查看。 |
| 管理员 | 在受保护入口开通、重置、冻结普通账号，继续使用原有壁纸管理功能；不能读取使用者真实密码。 |

首版包含公开目录、图片/视频预览、本地下载和设置、受控账号开通、登录与退出、强制首次改密、个人收藏及必要的管理操作。**下载和设置属于首版发布门槛**，不沿用早期 API 文档的“P1 建议后续”分期。

首版不包含公开自助注册或找回、邮箱/短信验证、第三方登录、多收藏夹、离线收藏写入、实时跨设备推送、签到、积分、等级、付费、自动轮播、远程 HTML 或可执行程序壁纸。签到与积分以后另立需求；基础壁纸能力不以登录或积分为门槛。

## 3. 发布阶段与关口

| 阶段 | 交付内容 | 进入下一阶段的条件 |
| --- | --- | --- |
| M0 账号安全关口 | 无共享密钥的桌面登录和安全续期；CUSTOMER/SYSTEM 隔离；首次改密、撤销和 Windows 恢复。 | 完整应用及实际部署的认证、授权、撤销和客户端联调通过。 |
| M1 首版交付 | 公开目录、收藏、本地下载导入、图片/视频设置桌面及多屏回归。 | 本文第 8 节的首版场景通过。 |
| 后续独立版本 | 签到、积分及其他成长功能。 | 另行确认规则、数据与验收，不预建功能。 |

M0 是安全关口，不是首版功能已交付的代称。现有 SAS 0.4.2 公共客户端原样换码不签发刷新令牌；后端已有固定 30 天的最小安全续期**候选实现**及定向测试，但默认关闭，尚不满足滚动六个月目标。完整 M0 仍缺候选适配、账号管理、首次改密、入口隔离、Windows 与部署联调。

## 4. 公开壁纸目录与预览

1. 主导航提供“在线壁纸”，保留现有本地库。首次进入加载公开目录，默认每页 20 条；卡片显示封面、标题和图片/视频类型。详情展示可用的描述、来源、版权及有效外部来源链接。缺失的可选信息不显示，描述按纯文本呈现。
2. 支持标题搜索（提交后查询）、全部/图片/视频筛选、刷新和加载更多。切换条件重置分页并忽略旧响应；仅成功后推进页码；下一页失败保留已显示内容并允许重试；按远端 ID 去重。业务失败、网络失败、格式异常与合法空结果必须区分。
3. 图片可预览。视频列表不自动播放，详情中由用户主动开始，离开详情即停止。封面或单条媒体失败只影响该项，保留元数据和重试入口。浏览、登录和预览不停止当前桌面壁纸。
4. 只展示后端判定为公开可见的内容。管理侧停用后，下次成功刷新不再列出；不要求实时推送。远端媒体仅接受有效 HTTP(S) 图片/视频，不执行远端程序或网页。
5. 媒体与海报地址分别选择；按已核查的备用、主地址顺序有界尝试并去重。`urlBase` 不当作媒体直链，也不拼造高清地址。具体可用域名、格式和真实分页响应仍需部署联调确认。

## 5. 账号、登录与安全

1. 复用 `sys_user` 的 CUSTOMER 类型和既有 userId；收藏关联该身份。不新增独立用户表，不自动迁移或合并其他账号。管理员经专用受保护入口开通普通账号、重置密码和冻结账号；服务端固定 CUSTOMER 类型，不接受调用方指定后台角色或他人归属，排除管理员保留身份。
2. 开通或重置时为每个账号生成独立随机**临时密码**，哈希保存并受控交付，不记录明文。首次登录后必须改密；改密前服务端仅允许必要账号状态、改密和退出，拒绝收藏等私有业务。重置和改密撤销旧授权，冻结禁止私有访问；解冻不恢复已撤销会话。
3. 桌面使用系统浏览器、授权码和 PKCE S256；校验本次 `state`、回调与一次性授权码。正式方案使用随机可用的 loopback 端口，先监听再打开浏览器；取消、超时或端口占用须清理监听及临时状态。桌面不内置共享 client secret，不把访问令牌直接延长至六个月，也不靠频繁浏览器再授权满足体验。
4. 已登录用户在 Windows 前台主动浏览、搜索、收藏、下载、设置壁纸或操作账号时，服务端确认实际使用并将该设备登录期限滚动延长至最近一次实际使用后的六个日历月；仅播放桌面壁纸、应用常驻、自动刷新或后台请求不计活跃。离线操作不延期，联网后仍有效的授权在下一次实际使用时延期，过期则重新登录；设备之间互不延期。重启后恢复仍有效授权。刷新凭据必须有客户端和用户绑定、有效期、抗重放及撤销能力；并发刷新不能恢复已撤销会话。401 最多协调一次恢复，403 不进入登录循环。
5. Windows 凭据使用 DPAPI CurrentUser，并与原 Lively 图库凭据分开存储。Token 只发往可信业务 API，不放进媒体/CDN 请求、URL 或日志。退出本机清理私有视图和本地凭据并撤销当前授权；远端撤销失败须如实提示。账号切换时丢弃旧账号的缓存、未完成动作和晚到响应。
6. CUSTOMER 不能访问任何管理入口或接口，SYSTEM 不能以普通用户身份读取他人收藏。私有数据从服务端认证主体确定归属；未登录和无权限分别返回 401、403。类型字段、菜单隐藏或单独的权限注解都不能代替完整路由隔离。

## 6. 收藏与本地使用

### 收藏

- 首版只有一个默认列表，按最近收藏时间倒序，每页默认 20 条。列表卡片和详情共享收藏状态；游客点击收藏时引导登录，成功后重新校验壁纸可用性再执行一次，取消登录不收藏。
- 收藏、取消均以服务端成功为准。重复收藏只保留一条且不改变原收藏时间；重复取消成功；取消后重新收藏获得新时间。数据库对用户和壁纸组合设唯一约束。离线写入明确报错，不排队假成功。
- 进入收藏页、恢复前台及手动刷新时同步服务器。下架或删除的内容保留可识别占位与取消入口，不返回失效媒体直链。收藏属于账号，下载属于设备；取消收藏不删文件，删本地文件不取消收藏。

### 下载与设置桌面

- 提供“下载到本地”和“下载并设为壁纸”。下载完成不自动改变桌面，除非本次动作明确要求设置。已下载项可直接设置，离线时可继续使用有效本地文件。
- 显示进度、取消、导入和可重试失败状态；未知长度不用虚假百分比。先下载临时文件，验证后导入现有本地库；图片/视频直链不能走原 Lively 图库 ZIP 安装流程。
- 以服务标识和远端 ID 关联本地资源，重复操作复用有效文件或在途任务；重启按真实文件恢复“已下载”状态。断网、磁盘不足、媒体损坏、取消或导入失败不得显示假完成。
- 设置桌面沿用现有屏幕选择与布局行为；成功以桌面核心结果为准。下架、退出或切换云账号不主动删除本机已下载的公开媒体。

## 7. 接口与数据边界

公开目录优先复用现有 `GET /rest/wallpaper/page` 与可见性查询；只有真实契约缺口需要时才增加版本化公开入口或详情接口。旧开放接口保持兼容。响应按现有 `R<PageResult<...>>` 解包，同时检查 HTTP 与业务结果；`records: []` 才是合法空页。`type=1/2` 分别映射图片/视频，远端 ID 无损保存，来源编码不当媒体类型，未确认时区的 `launchTime` 不擅自做 UTC 换算。

私有收藏接口与匿名 `/rest/**` 分开，拟采用 `/client/v1/me/favorites` 下的分页、批量状态、幂等收藏与取消；最终路由及 DTO 在实现前与现有后端冲突和真实样例核对。归属仅从认证主体读取，私有响应禁止共享缓存；公开响应不含个人收藏字段。业务新增表以收藏关系为主，保存用户 ID、壁纸 ID、最小标题快照和收藏时间；不为后续签到积分提前建表。媒体/CDN 请求不附带用户 Token。

部署 API 根地址、网关前缀、匿名读取、资源域名、防盗链、实际成功码、分页起点和来源枚举尚需真实环境确认；不能从管理前端代理地址或演示 JSON 推断生产契约。

## 8. 首版验收

| 范围 | 必须通过的结果 |
| --- | --- |
| M0 认证与权限 | 正确/错误 PKCE、state、回调、授权码重放；无共享密钥续期、前台实际使用滚动延期、后台刷新不延期、设备独立期限与连续六个日历月不活跃过期；重启恢复、刷新重放与并发撤销；游客/CUSTOMER/SYSTEM 的公开、本人、他人和管理接口矩阵；独立临时密码、强制改密、重置及冻结失效。 |
| Windows 登录 | 系统浏览器与 loopback 回调、端口占用、取消/超时、DPAPI 保存与恢复、退出及账号切换；失败不妨碍公开浏览和当前壁纸。 |
| 目录与预览 | 真实 API 数据、中文搜索、类型筛选、分页重试不跳页、旧响应不覆盖新条件、业务失败不假空；图片预览和视频主动播放/离开停止；封面或备用资源失败局部降级。 |
| 收藏 | 两设备并发仅一条、重复取消成功、刷新同步；下架/删除占位可取消且无媒体直链；账号切换无数据串扰；离线不假成功。 |
| 本地使用 | 图片/视频下载、取消、导入、重启、重复下载、离线使用及多屏设置；断网、损坏、磁盘不足与导入失败无假完成；收藏和文件删除互不影响。 |
| 界面与回归 | 现有深浅主题、窗口缩放、键盘可达；浏览或登录时已有桌面壁纸持续运行，原有管理登录和公开消费者保持可用。 |

后端认证与收藏应在实际 HTTP 安全链和持久层验证；Windows 媒体与多屏行为需在真实机器联调。当前 36 项定向认证测试和 WAR 构建只证明安全续期候选的已测范围，不能替代上述首版验收。

# 首版复用 CUSTOMER 账号并由管理员开通

2026-10-30 确认：复用后端已有 `sys_user` 的 CUSTOMER 类型，收藏关联其 userId；首版正式运营，由管理员通过受控入口开通普通账号、重置密码，暂不提供自行注册或找回，不新增独立用户表。这比建立第二套身份体系更符合现有能力；后续若提供自行注册，可继续复用这些用户身份。

CUSTOMER 类型不是自动权限边界。必须补齐普通用户和管理员的入口及接口隔离，普通账号不授后台角色；现有后台新增方法强制 SYSTEM，不能直接当作普通账号开通接口。已登录用户在 Windows 前台主动操作时，由服务端确认该设备的实际使用并将期限滚动延至六个日历月后；离线使用、后台自动刷新、应用常驻和仅播放壁纸不计活跃，设备之间互不延期。此目标仍需单独验证安全续期与撤销能力，不能照搬带共享密钥的示例配置。

管理员开通和重置使用每个账号独立的临时密码，首次登录后必须修改。管理员重置后撤销旧登录；强制改密由服务端约束，不能仅依赖客户端提示。

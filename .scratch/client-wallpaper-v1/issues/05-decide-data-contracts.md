# 确定目录、收藏与本地使用契约

Type: grilling
Labels: wayfinder:grilling
Mode: HITL
Parent: ../map.md
Blocked by: 02

## Question

依据公开目录与本地使用调查，确定首版稳定契约及最小变化：是否需要新公开详情/可用性接口；私有收藏路由、分页和不可用占位；媒体候选顺序与允许格式；远端身份如何关联本地库，如何判定重复下载、有效文件及同 ID 内容变化。

保留旧公开接口兼容，收藏归属来自认证主体，收藏与本地文件独立；不凭猜测的域名和示例响应定生产契约。明确哪些选择有源码依据，哪些需要实际部署验证，不为尚未使用的能力增加 API 或表。

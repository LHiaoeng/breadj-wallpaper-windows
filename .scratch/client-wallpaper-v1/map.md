# 光影壁纸首版交付决策地图

Labels: wayfinder:map

## Destination

厘清《光影壁纸 Windows 客户端首版 PRD》从当前状态到首版交付的所有关键决策，形成可交接的实施路线。地图完成意味着关键方案、契约、交互和验收条件明确，可以另行拆分实施任务。

## Notes

- 产品基线：[首版 PRD](../../docs/光影壁纸Windows客户端首版PRD.md)；执行细节：[既有规格](spec.md)。遵守已接受 ADR 与术语表，不另立产品规格。
- 用户于 2026-10-30 确认：覆盖 Windows、Java 后端和账号开通/重置/冻结所需的最小管理界面；按独立“在线壁纸”入口规划；收藏、登录及下载状态通过原型与用户定案。首版按正式运营交付，账号由管理员开通，暂不提供自行注册；前台实际使用分别滚动延长各设备登录，连续六个日历月无实际使用才过期，后台自动刷新和离线操作不延期。
- 每次继续先读 wayfinder；HITL 决策使用 grilling 和 domain-modeling；调查使用 research；交互验证使用 prototype。
- 本地图只规划。M0 必须先验收，之后交付 M1；地图上的依赖仅表示“做决策所需的前提”，不等于允许提前交付功能。
- 本地票位于 issues/，标题即名称。Type/Labels 表示类型；未写 Status 表示未领取，开始前写 claimed，完成后写 resolved；依赖使用 Blocked by 的实际文件编号。仅选所有依赖 resolved 且未领取的票。
- 研究允许并行；其他每次只解决一票。主 agent 统一写文件，子 agent 只读，不递归委派。研究成果由主 agent 保存到独立 research/ 分支并推送，不开 PR、不合并；票链接成果。
- 已有 M0 进展是证据入口，需与源码核对，不因旧测试通过推定整个 M0 完成。

## Decisions so far

<!-- 仅索引已解决票；PRD 和本轮确认是既有约束，不伪装成已解决的票。 -->

- [核实账号安全候选与三端账号管理的真实接入边界](issues/01-research-account-boundaries.md)：续期及资源边界已有候选，账号管理、首次改密和三端完整联调仍有缺口。
- [核实公开目录与 Windows 本地使用的可复用契约](issues/02-research-catalog-local-seams.md)：目录可复用，收藏需新增真实业务；媒体下载应衔接本地导入，不能使用图库 ZIP 安装。
- [确定 M0 登录与普通用户账号操作方案](issues/03-decide-account-route.md)：独立普通用户管理与登录入口；实际使用按设备滚动延长至六个日历月，安全撤销与首次改密必须联调。

## Not yet specified

- 真实环境与原型暴露的兼容问题，可能要求补充资源可用性或本地安装的决策；待调查和交互验证后再具体化。登录滚动续期、随机回调及浏览器会话已成为明确的调查票。
- 若实际部署验证暴露新增前置条件，再据具体证据创建环境准备票，不预设供应商、域名或迁移方案。

## Out of scope

- 实施生产功能、执行数据库迁移、变更真实账号或启用续期候选；实施须在路线清楚后另立任务。
- 更改游客免费使用、CUSTOMER 复用、管理员开通且暂不提供自行注册、单收藏列表、首版包含下载设置等已确认边界。
- 公开注册、自助找回、签到积分、付费、自动轮播、多收藏夹、离线收藏队列及重写播放核心。
